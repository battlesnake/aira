Master CI (test + race) has been red since PR #219 (AIRA-313): TestConfineKillSameClaudeSessionFromAnotherWorktree (cmd/aira/dispatcher_inprocess_test.go) hard-fails on a host with no aira.slice (the GitHub runner), because the daemon answers the default-slice `confine list` with E_INTERNAL "aira.slice not found" instead of E_CONFINE_UNAVAILABLE. The explicit-slice branch of runner.ResolveConfineManagementSlice already wraps via confineUnavailable(); the default-slice branch (resolveDefaultConfineSlice) returns the raw error. Fix: wrap the default branch too, so a missing/inactive slice is the stable E_CONFINE_UNAVAILABLE code and the test helper (which already treats it as unlistable -> SkipOrFailRealCgroup) skips on slice-less hosts and still hard-fails under AIRA_REAL_CGROUP=1. Regression test at the resolver seam. Not in scope: TestVRAMContendedJobIsHeldNotRefused race flake (seen once on #218).
