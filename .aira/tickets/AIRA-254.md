Follow-up enhancement to the v0.10 aira board (AIRA-252). Three parts: (1) a persistent info pane in the top ~1/4 showing the selected ticket's details, live as the cursor moves — on a wide terminal a two-column split with the right >=50% dedicated to the wrapped body and the left to metadata fields; on a narrow terminal a stacked layout with a body preview. The full title always wraps and is never truncated. Metadata/body fetched debounced on selection-settle and rendered as labelled lines (NOT JSON), honest loading/unevaluated. (2) The Enter drill-in becomes 'expand' — the same readable renderer in a full-screen scrollable overlay (for long bodies). (3) A full-width column toggle on 'f' that shows only the focused column at full width via the existing boardVisibleColumns width seam. Motivation: the current drill-in shows a raw json.MarshalIndent dump (owner: 'just gives me a JSON dump, nothing useful'), and narrow columns truncate titles. Read-only; project board only (not the all-projects overview). Opus builds, Fable reviews.
