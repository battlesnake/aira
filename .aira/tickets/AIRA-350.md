Owner decision 2026-11-18 (supersedes the earlier dynamic lane, which could not prove a head cannot starve): "go back to a fixed slice that is separate to the main slice reservation. Its max size is always fixed. The main slice reduces its admission ceiling based on available RAM as it currently already does." Earlier wording: "a fixed slice of x GB (4 or 8), which jobs requesting <= y GB (1 GB) are admitted to before using the main slice; if full they use the main slice; default mode only, not CI mode."

Design: a separately-booked pool inside the one queue and ledger (AIRA-228: one daemon queue, one ledger, one-slice guard; not a second cgroup unless the spec shows it is needed). Lane bookings never count against the main ceiling; the main ceiling is computed exactly as today (pressure term from available RAM). A job-level waiter with ledger charge <= y that fits the lane (lane bookings + charge <= x) and the physical/CPU/VRAM gates is granted in the lane, regardless of the head-of-line freeze and bypass budget. Lane full or job larger: today's behaviour in the main pool. x is fixed (not carved from the main ceiling). Spec: docs/superpowers/specs/2026-11-18-fixed-small-lane-design.md. Correctness-critical (admission, host memory exposure up to x): two-loop, Opus builds, Fable reviews, Sol xhigh.

Evidence and prior review: docs/superpowers/specs/2026-11-18-small-job-lane-design.md (dynamic lane, 4 rounds, not approved) and docs/dev/aira-350-*.

Spec round 1 (2026-11-18): lane eligibility and use are in cap bytes (reserve), not ledger charge (a resize or discount puts the cap above the booking); the main pool's static maximum is memory.max - x so bookings never pass the kernel cap; a lane grant leaves the head's CPU, VRAM and physical need; --delegate-ram parents are not eligible; closed behind a --front head by default. Defaults x=4G, y=1G. Replay (docs/dev/aira-350-fixed-lane-replay.py, upper bounds, no CPU gate): x=4 removes 68.6-79.5% of small-job wait-hours, x=8 84%. Residual: bookings may exceed today's pressure ceiling by x (worst-case MemAvailable floor 6 GiB at x=4, 2 GiB at x=8, 10 GiB today). Owner questions: Q1 additive vs partition on the pressure term, Q2 lane behind a pushed head, Q3 x=4 or 8.
